Project timeline

  1. Research · Gathered project needs and task flows.
  2. Design in Figma · Created the lilac interface and components.
  3. Build · Assembled the responsive HTML and CSS pages.
  4. Testing · Reviewed layout and navigation.
  5. Presentation · Prepared the final project showcase.

Design choices

Lilac tones keep the workspace calm; cards make information easy to scan. Status colors use purple for open, yellow for in progress, green for done, and pink for overdue tasks.
